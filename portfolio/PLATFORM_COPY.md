# Personal Portfolio

## Project Title

ProposalFlow — Full-Stack SaaS Proposal Management Platform

## Short Description

A production-ready SaaS application for creating, sending and tracking commercial proposals.

ProposalFlow helps freelancers, agencies and service businesses manage clients, reusable services, proposal pricing and final client decisions through one focused workspace.

## Full Description

ProposalFlow is a full-stack SaaS product developed from initial product scope to production deployment.

The application allows users to manage clients and reusable services, create proposal drafts, calculate pricing and discounts, publish secure public proposal links and receive accepted or rejected client responses.

The system includes authentication, company settings, client and service management, proposal status tracking, public proposal pages and a real-time business dashboard.

I designed and developed the frontend architecture, responsive interface, Supabase database schema, authentication flow, Row Level Security policies, pricing logic, public proposal access and production deployment.

### Main Features

- User authentication and password recovery
- Protected SaaS workspace
- Client management
- Reusable service catalogue
- Proposal creation and editing
- Quantity and unit-price calculations
- Fixed and percentage discounts
- Draft, sent, viewed, accepted and rejected statuses
- Secure public proposal links
- Client accept and decline workflow
- Proposal activity dashboard
- Company profile and logo upload
- Responsive desktop and mobile interface

### Technology

Next.js, React, TypeScript, Tailwind CSS, Supabase Auth, PostgreSQL, Supabase Storage, Row Level Security, Zod, Vercel and GitHub.

### Live Product

https://proposalflow-six.vercel.app
